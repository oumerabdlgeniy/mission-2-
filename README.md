# Student Grade Management System

## Description

This project is a Student Grade Management System built with JavaScript. It allows users to add students, calculate their total and average scores, determine grades, and manage student records.

The project demonstrates the use of advanced JavaScript concepts including callback functions, arrow functions, higher-order functions, rest parameters, and closures.

## Features

- Add student information
- Calculate total score
- Calculate average score
- Determine student grade
- Display multiple students
- Pass/Fail result

## Technologies Used

- HTML5
- JavaScript (ES6)

## JavaScript Concepts Used

- Functions
- Arrow Functions
- Callback Functions
- Higher-Order Functions
- Rest Parameters
- Closures
- Arrays and Objects
